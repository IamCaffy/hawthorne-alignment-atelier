# Hawthorne Alignment Atelier

**People · Principles · Possibilities**

An independent, fan-made Dungeons & Dragons character-development resource using an expanded **81-point alignment framework**.

## Explore the framework

**[Explore the free interactive 9×9 alignment grid](https://iamcaffy.github.io/hawthorne-alignment-atelier/framework.html)**

The framework scores a character along two independent dimensions, each from 1–9:

- **Lawfulness (X):** commitment to a consistent personal code—not simply obeying laws or authority.
- **Goodness (Y):** concern for others' welfare, dignity, and autonomy.

Coordinates always follow the form **(Lawfulness, Goodness)**. The site includes all 18 classification definitions, examples, and roleplaying prompts. It works without a login, AI API, or plugin installation.

The full ChatGPT **Hawthorne Alignment Atelier** plugin provides character assessment and personalized alignment posters. Public directory listing is not yet available. The website is a public reference, not an AI-based assessment or poster generator.
